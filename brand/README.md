# VBK — Brand paket

Zvanični logo Veterinarske Banke Krvi je **Higgsfield original** (`../logo-v1.png`, 2048×2048).
Sve verzije ovde su izvedene direktno iz tog PNG-a obradom piksela — ništa nije precrtavano.

## Zvanični fajlovi (PNG, iz Higgsfield originala)

| Fajl | Namena |
|---|---|
| `logo-v1-transparent.png` | Master za upotrebu — original bez bele pozadine |
| `logo-v1-white.png` | Bela verzija za tamne podloge (šapa je proziran otvor) |
| `logo-v1-black.png` | Mono verzija — pečat, fakture, jednobojna štampa |
| `icon-512.png` | PWA / app ikonica |
| `apple-touch-icon-180.png` | iOS home screen (neprozirna pozadina, po Apple pravilu) |
| `favicon-32.png`, `favicon-16.png` | Favicon |

## Boje (izmerene iz originala)

| Boja | Hex | Upotreba |
|---|---|---|
| Krv — svetlija polovina | `#D7292A` | Primarna brend boja, CTA, akcenti |
| Krv — tamnija polovina | `#BB242B` | Hover stanja, senke |
| Teget (predlog za tipografiju) | `#1D3557` | Naslovi, tekst uz logo |

## Napomene

- 2048 px je dovoljno za štampu pamfleta (17 cm na 300 dpi) i sve web/app potrebe.
- Za veliki format (baner, izlog) trebaće profesionalna vektorizacija originala.
- `vbk-*.svg` fajlovi su odbačeni ručni nacrti — slobodno ih obrisati.
